МИР: ТЕТРИС — ГОТОВЫЙ ПАКЕТ ВИЗУАЛОВ ДЛЯ CODEX

Все иконки и персонажи сохранены в PNG с прозрачностью.
Все имена файлов — латиницей, чтобы пути стабильно работали на GitHub Pages.

СТРУКТУРА
header/            — широкая шапка игры. Текст уже встроен в изображение.
yashka-chips/      — 9 коллекционных фишек Яшки.
bonuses/           — 10 крупных изображений игровых бонусов для карточек и окон.
special-blocks/    — компактные символы для отображения внутри клеток тетриса.
task-icons/        — значки типов вопросов и мини-заданий.
question-objects/  — 24 предмета для вопросов «что лишнее», «что пропало», «найди пару» и т. п.
yashka-ui/         — 6 интерфейсных состояний Яшки, взятых строго из канонического референса.
reference/         — исходная развёртка Яшки для контроля канона.
asset-manifest.json — список файлов, назначение и размеры.

ВАЖНО ДЛЯ ВЁРСТКИ
1. Не встраивать кнопки, тексты и числовые показатели в изображения. Их делать HTML/CSS.
2. Крупные бонусы показывать в модальных окнах или карточках, а special-blocks — внутри клеток игрового поля.
3. Для изображений использовать object-fit: contain; pointer-events: none; user-select: none.
4. Коллекционные фишки не расходуются: открытая фишка остаётся в альбоме. Одновременно можно начислить одно применение соответствующего бонуса.
5. Для закрытой фишки не нужен отдельный рисунок: применить CSS filter: grayscale(1) brightness(.35), добавить замок и непрозрачность.
6. Яшка не должен растягиваться. Сохранять пропорции изображения.
7. Вопросы должны быть короткими, без штрафа за ошибку. При неверном ответе показывать yashka-ui/04_yashka_support.png.

ПРОВЕРКА КАНОНА ЯШКИ
Розовый овально-каплевидный персонаж; большие карие глаза; румянец и точки на щеках; тонкие руки и ноги. Не заменять его животными, человеком, сердцевидным персонажем или персонажем с аксессуарами.
